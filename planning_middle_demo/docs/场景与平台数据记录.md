## 四、平台参数与公开 Gazebo 模型的对应关系

登记在 `config/platform_references.json` 的 `profiles.*.gazebo_parsed` 块（2026-10-26 解析自素材包，含逐 link 质量与控制器限幅，均为**解析值而非实测**）：

| 类别 | 对应公开模型 | 关键解析值 |
| --- | --- | --- |
| UGV | gz-sim `vehicle_blue`（DiffDrive 插件） | 整机 6.14 kg；底盘碰撞盒 2.01×1×0.57 m；轮半径 0.30 m、轮距 1.25 m；线速度限幅 ±0.5 m/s，角速度限幅 ±1 rad/s |
| TANK | gz-sim `simple_tracked`（TrackedVehicle 插件） | 整机 28.26 kg；底盘盒 0.50×0.24×0.139 m；履带中心距 0.4 m；TrackController 线速度限幅 ±1 m/s |
| PLANE | PX4 `rc_cessna` | 12 个 link 合计 1.67 kg（base_link 0.95 kg）；机体盒 0.65×0.08×0.10 m；IMU 250Hz、NavSat 30Hz、气压 50Hz、磁力计 100Hz |
| WING | ArduPilot `zephyr`（飞翼） | 6 个 link 合计 1.9 kg（wing 0.5 kg + lift_drag 0.1 kg）；IMU 1000Hz；带 LiftDrag + ArduPilotPlugin |

对应关系是"能力画像的公开参照"，**不是**同源模型绑定：四类平台的外形/能力
选型来自 `机器人移动话题说明.md`，公开模型只用来把"速度限幅、尺寸量级、
传感器频率"这类量级说清。规划器（planner_v2）目前只消费场景 JSON 里的
✎ 演示参数；接真实下层时，应把上述解析值代入 `fleet.py` 的参数表并重新标定。

**平台图标（小形状 + r 编号）**：■ 方块=UGV 轮式车（r01-r04）、◆ 菱形=TANK 履带车（r21/r22）、▲ 三角=PLANE 固定翼（r31/r32）、✕ 叉=WING 飞翼（r41/r42）。图标位置即出发阵地，全部**就近前出部署**在各自任务区附近。

**虚线（规划航线）**：每条虚线 = "某平台出发位 → 被指派的作业点"，颜色跟随所属作业。虚线上打点处是线段中点方向示意。注意两条关键连线：
- r04（方块）到 J2/J4 的两条长虚线，和 r21/r22（菱形）到 J2 的连线——封控和突击都需要这三台车**先做 J2 再转场做 J4**（串行调度），J4 的航线颜色更浅/时刻更晚正是排程靠后的体现。
- r32（▲）有两条紫色/蓝色线：它先在路口做 J1 巡逻，之后飞到无线电塔参与 J3 协同侦察——一架飞机串两个任务。
- r31（▲）到 J5 的绿色短线很短，说明飞机就在坚守点旁待命。

**悬停与时间口径**：鼠标悬停任意圆点/图标可看完整计划（出发 t、开工 t、完工 t、窗口、成员）。时刻口径：开工 = 出发 + travel（真实运动含转向与爬升耗时），完工 = 开工 + 作业时长；J2 开工晚（t=28）是因为要等三台车陆续到位凑齐 crew=3。

**局限声明**：规划图上的航线是直线示意；执行层的**避障路径**见第八节（2026-10-28 补）。第八节之前，`motion=real` 只做"先转向、再直行、飞机带爬升"，没有路网寻路；现在地面平台已改为按真实建筑碰撞体的膨胀栅格 A* 路径机动，空中平台仍直飞（越障假设成立）。

## 七、复现方式

```powershell
# 跑一次（瞬移，快）
py -3.14 run_demo_v2.py --scenario scenarios/simple_city.json

# 跑一次（真实运动，GoalController 闭环）
py -3.14 run_demo_v2.py --scenario scenarios/simple_city.json --motion real --max-ticks 200

# 重新生成规划地图
py -3.14 gen_map.py
```

### 8.2 避障参数与效果

| 项 | 值 | 说明 |
| --- | --- | --- |
| 膨胀半径 | 0.6 场景单位 ≈ 1.7 m | 平台半径 + 安全余量，A* 与捷径平滑都用它 |
| 栅格分辨率 | 0.2 场景单位 ≈ 0.57 m | 43 × 36 单位地图约 2.2 万格 |
| 平滑 | 整段可通行才走捷径 | 不做"切角"平滑，避免贴墙 |
| 跟随 | 视线可达的前瞻点 + 前向安全投影 | 投影被挡则停车转向并局部重规划 |
| 点位吸附 | `nearest_free`，J4 吸附 2.90 单位、J6 吸附 1.55 单位 | 吸附距离写入产物，不隐藏 |

典型绕行（`behavior_demo` 实测）：

- rover_01 → J6：直线 4.10，绕行 9.15（2.23×）——直线正穿 salon/law_office 商铺排；
- rover_01 → J4：直线 29.18，绕行 32.25（1.11×）——绕过警察局主楼；
- 全场景 13 段"接近路径"里 4 段直线被建筑挡住，均改走 A* 路径；行为内部 99 段路径全部可通行。

### 8.4 还没做的

- 没有 SLAM/感知：地图是离线已知的，未知区域不会自己长出来；
- 没有动态障碍：只靠前向安全投影触发局部重规划，没有预测/博弈；
- 空中平台不参与地面绕障（默认越障），低空突防需要另一套三维地图；
- 其余 500+ 场景对象（树、路灯、车辆）未建图，穿模风险仍在，只是不在本演示的作业走廊上。
