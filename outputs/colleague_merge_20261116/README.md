## 使用

- 正常启动 `启动工作台.cmd`，使用最新版本的工作台。已有旧服务时按终端给出的新端口访问。
- “实验与报告”新增配置变更后子任务切换统计；“运动指令导出”提供完整运动 JSON、CSV 和独立 ROS2 节点。
- 旧运行不追写新指标或运动文件；重新运行或续算后才产生当前版本的归档。
- 下载同目录 `ros2_plan_node.py` 与 `motion_commands.json`，可用 `py -3 ros2_plan_node.py --dry-run` 离线核对；有 ROS2 的目标环境可运行该节点。`--plan plan.json` 显式使用静态计划，`--time-scale N` 将时长放大 N 倍、速度除以 N。
