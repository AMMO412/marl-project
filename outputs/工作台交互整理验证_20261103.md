# 工作台交互与布局整理验证

验证日期：2026-11-03。实际服务：http://127.0.0.1:8772/；后端版本 `2026-11-03-workbench-ui`，页面版本 `workbench-ui-20261103`。

## 修改范围

- 将 index.html 内的多轮布局补丁和独立刷新定时器替换为 workbench_ui.js / workbench_ui.css；保留现有地图绘制与设备图标。
- 前端增加统一任务选择、按回放变化渲染的右侧详情、可拖动及键盘调整的分栏、本地宽度记忆与窄屏上下布局。
- 执行摘要、路径记录使用共享展示函数，右侧不再读取尚未打开的弹窗内容；高度仅采用当前回放时刻以前的有效样本，显示采样点、纵轴范围和反馈时间。
- 修复空记录导航、运行载入失败与竞态、任务选择被覆盖、自定义仿真步数被覆盖及重复提交问题；独立视图切换不再自动开始播放。
- 文件页区分融合版入口和基座参考，增加现有工程说明的预览；静态服务增加两个展示资源白名单和两个文档映射，并更新服务版本。

未修改规划器、任务规则、执行、判定和任务 schema。没有强化作战控制输出或 Gazebo 执行链路；现有相关内容原样保留。测试未启动新的任务执行；提交测试由浏览器拦截为模拟失败响应。

## 验证结果

Microsoft Edge 无头浏览器通过 41 项断言，未记录页面脚本错误。

- 五个导航页往返、空 catalog、运行载入失败提示、快速载入时后请求优先。
- 查看任务不改变时刻、倍速与播放状态；多任务选择在回放更新后保持。
- 折叠状态保持；路径不依赖弹窗；运行重新加载清理派生展示。
- 播放、暂停、时间轴拖动；专属视图切换不自动播放并带回时刻。
- 鼠标及键盘拖动分栏、宽度记忆；图层开关保持；高度反馈时间显示。
- 新建表单自定义步数保持、重复提交拦截、隐藏效果字段不提交、失败恢复按钮。
- 融合入口文档预览成功；1366×768、1920×1080、640×900 无横向溢出，桌面播放器在窗口内可见。
- JavaScript 语法、服务端 Python 编译及按 CRLF 约定的变更格式检查通过。

机器可读结果与实测截图位于 [workbench_ui_20261103](workbench_ui_20261103/)。
