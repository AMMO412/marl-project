# 城市地图交换包

使用根目录 `启动工作台.cmd`，在顶部选择住宅街区、密集城区或公园与斜街混合片区；也可通过“导入地图”读取这里的 `map.json`。

| 地图 | 源几何范围 / 米 | 建筑 | 路侧障碍 |
| --- | --- | ---: | ---: |
| residential | 800 × 800 | 172 | 116 |
| downtown | 1200 × 1000 | 516 | 196 |
| mixed | 1600 × 1200 | 290 | 240 |

这些是合成街区。JSON 是源几何，GeoJSON 是本地米制交换格式，SDF 是静态场景导出，尚未在 Gazebo 验证。运行实际读取 `planning_middle_demo/interop/urban_maps/` 的随包 JSON，并为规划和显示采用同一变换。

**内置三图已接入规划、随机任务和本地执行；任意自定义地图文件导入仍仅为只读显示**。这里的纯地图导出不含任务或算法结果。地图查看不等于执行成功，早期 `import_check.json` 和截图只证明生成时的浏览器导入检查。
