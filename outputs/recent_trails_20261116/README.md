# 默认近期拖尾

工作台所有任务的地图默认显示智能体最近 10 秒的实际运动轨迹。新载入运行恢复近期模式；聚焦任务或成员仍保留其他可见成员的拖尾。专用任务回放仍只显示参与成员，动作流程图保持流程示意。

统一处理稀疏采样、时间窗边界与当前已播放位置；不同指令、任务或失联/结束状态之间不虚连轨迹。不改变规划、运动或历史文件。静止成员不绘制没有长度的线。

浏览器核对五类任务、聚焦前后成员数量、默认恢复、返航、稀疏采样、完整轨迹与时间窗口；结果见 [verification.json](verification.json)，截图见 [all-agents-recent-trails.png](all-agents-recent-trails.png)。验证使用既有运行，只证明显示逻辑，不代表任务执行成功或外部平台联调。

当前服务直接读取静态文件，在原工作台页面刷新即可使用，无需重启正在运行的仿真。
