## 打开方式

双击工程根目录的 `启动工作台.cmd`，在顶部选择城市地图。端口以启动终端显示为准；旧“打开场景工作台.cmd”当前不存在。

在工作台上方“选择城市地图”切换三张内置地图，或点击“导入地图…”选择下面的 `map.json`。滚轮缩放，拖动平移，“返回运行视图”回到原来保存的运行记录。

## 场景产物

正式地图包位于 `outputs/urban_maps_20261112/`，每个地图目录只有三种几何文件：

| 文件 | 用途 |
| --- | --- |
| `map.json` | 工作台导入的纯地图。包含边界、建筑、道路网络、公园、路侧障碍、高度与地图摘要 |
| `map.geojson` | 通用几何交换数据；采用本地米制坐标，不是经纬度 |
| `map.sdf` | SDF 1.7 静态场景，包含地面、道路外观、建筑及路侧障碍碰撞体 |

根目录 `catalog.json` 是地图目录。地图都是合成街区，非参考图片对应的真实城市；固定地图种子与摘要可追溯几何变化。建筑与路侧障碍共用同一份几何；树木和公园目前为二维装饰。

## 重新生成

在工程根目录运行，只需 Python 标准库：

```powershell
python scenario_lab/urban_scenes.py --maps-only --out outputs/urban_maps_20261112
```

默认不再生成巡检任务、参考路线或单独网页。此前独立预览已移到工程外；当前历史材料位置见[归档索引](../outputs/历史产物索引.md)；旧巡检样例只有显式指定 `--with-inspection` 才生成。

## 接入与验证边界

已经完成现有工作台的地图选择、JSON 文件导入、平移缩放及返回运行视图。三张地图和文件导入已在浏览器检查，未出现脚本异常。导入期间隐藏原运行的任务与平台信息，防止把旧任务误画到新地图。

**内置的住宅街区、密集城区、混合片区已接入规划、任务随机生成和本地执行，运行资产在 `planning_middle_demo/interop/urban_maps/`。导入任意自定义 `map.json` 仍仅用于只读显示**，不会自动改变导航约束、任务或运行记录；不能把内置地图集成推及所有导入文件。
