# 项目结构与维护

主工程保留 `planning_middle_demo/` 原路径，不搬核心模块。界面入口采用根目录 `启动工作台.cmd`；原生桌面是兼容选项。

| 区域 | 保留与清理规则 |
| --- | --- |
| 源码、模板、地图、SDF、模型、测试、启动与构建脚本 | 保留；不能按文件日期或是否被主入口直接导入判断无用 |
| `desktop_app/dist/data/runs/` | 工作台真实输入、结果、版本和回收站；本轮全部保留，不按失败/未完成筛除 |
| `planning_middle_demo/outputs/` | 历史/命令行/专项运行；本轮保持原位，不据旧保留名单判断实际内容 |
| 根 `outputs/` | 仅保留必要道路/地图、接口样例、当前完成度和精选近期证据；历次备份/对照移到项目外 |
| `.work/`、`.workbuddy/` | 含唯一脚本、诊断、恢复快照和浏览器测试依赖；禁止整体清空 |
| `desktop_app/dist/`、`lib/` | 保留当前 exe、DLL、许可证、日志、数据；不为精简而移除正在使用的运行依赖 |
| `.git/` | 保留；不重置、不清理共享修改、不自动提交 |

归档采用“清单 → 源哈希检查 → 移出 → 目标哈希检查 → 修复文档链接”，原文件可按清单恢复。本轮不承诺减小整个磁盘占用：可恢复归档位于工程外，主要减少活动项目中的冗余。不会重建已经失效的历史目录。

清单与验证见 [本轮精简记录](../outputs/项目精简_20261116/README.md)。新运行正常生成，不为控制目录大小删除用户结果；确需删除某轮，应使用软件记录管理或明确按运行编号操作。
