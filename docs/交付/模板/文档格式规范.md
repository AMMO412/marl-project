# 文档模板与格式规范

## 1. 页面与字体

- A4 纵向，页边距上下 2.54 cm、左右 3.17 cm（可按单位模板调整）。
- 中文正文宋体小四，标题黑体；英文/数字 Times New Roman 或 Calibri。
- 行距 1.5 倍；表格内文字五号。

## 2. 文档结构

1. 封面：软件名称、文档名称、版本号、日期、单位。
2. 文档控制表：编号、版本、日期、编写、审核、批准、修订记录。
3. 目录。
4. 术语与缩略语。
5. 正文。
6. 限制与未实现项。
7. 附录（可选）。

## 3. 编号规则

- 章节：1、1.1、1.1.1。
- 图：图 1-1、图 1-2。
- 表：表 1-1、表 1-2。
- 用例：TC-功能-001。
- 证据：EV-001。

## 4. 内容规则

- 每个指标标注“已验证 / 未验证 / 未实现”。
- 截图带版本号、日期、场景名。
- 不把单次运行写成统计结论。
- 不把本地演示写成真实平台联调。
- 每个结论对应证据编号。
