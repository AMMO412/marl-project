## 用例分组

- `TC-INST-*`：安装、启动、卸载、升级、回滚。
- `TC-FUNC-*`：五类任务、异常模式、配置编辑、回放编辑、运行记录。
- `TC-INT-*`：4.1/4.2 接口、工作台 HTTP API、JS 桥。
- `TC-ROB-*`：端口冲突、后端崩溃、WebView2 缺失、数据损坏、断网。
- `TC-COMP-*`：Win10/11、DPI、中文/空格路径、小屏。
- `TC-PERF-*`：启动、加载、回放流畅度、内存/CPU。
- `TC-SEC-*`：仅本机监听、外部访问拒绝、日志无敏感信息。
- `TC-DATA-*`：样例运行、空目录、损坏记录、数据目录迁移。

## 通过准则

- P0/P1 缺陷关闭。
- 五类任务和三种优化目标有实测证据。
- 未实现项进入遗留问题清单。
