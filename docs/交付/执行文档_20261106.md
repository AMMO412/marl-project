## 4. 演示脚本

1. 双击 `MARL界面预览.exe`。
2. 确认原生布局与工具栏。
3. 场景下拉选 `interop_containment`。
4. 点“运行”，等待生成新记录。
5. 自动进入“任务视图”，观看真实回放。
6. 在左侧任务/平台节点、右侧属性、底部日志之间切换。
7. 打开“运行记录”，双击另一条运行。
8. 点“刷新”“任务视图”“播放/暂停”。
9. 打开“关于”，确认本地演示与 Gazebo/UE5 边界说明。
