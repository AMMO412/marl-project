# 工作台场景地图

工作台底图从 `资料/接口说明/container_00_combined_scene.sdf` 和本地 `models/` 读取，入口为 `planning_middle_demo/workbench_scene.py`，复用 `sdf_state.py` 和 `city_nav.py`。仅在运行声明同一 SDF/世界时显示，不给其它场景套底图；旧场景的缩放和平移同步应用于地图。

当前可解析：草坪地面 1 块，道路/广场 5 块，静态障碍 39 个（花坛 20、围墙 8、标识柱 5、建筑 6），地标位置 14 个。建筑来自本地 DAE 外包络，是俯视近似。

两处 `baylands` 湿地和一处 `yosemite` 山地只有模型引用，本地缺模型。工作台仅按 SDF 位姿标注位置与缺失状态，不绘制猜测的水岸、山体或碰撞范围。

`scene_map` 是当前 SDF 的展示底图，带来源及 SHA-256；历史运行的输入、规划约束、轨迹和报告保持原值。显示更多静态元素不表示历史规划已使用这些元素，也不代表 Gazebo 物理联调。

图例直接调用地图的 `drawPlatformIcon`，避免另用方块/菱形表达不同的图标。颜色含义随任务/编组视图变化。

验证：工作台相关 16 项测试运行，14 项通过、2 项因历史记录已归档跳过；浏览器核对桌面及窄屏、图层切换与适应视图，无脚本异常。截图位于 `.work/sdf_map_20261031/`。
