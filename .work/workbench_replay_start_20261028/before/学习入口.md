## 目录用途

| 目录 | 存放内容 |
| --- | --- |
| `robot_navigation_lab/` | 独立普通机器人导航工程；场景、任务、工具、测试与运行结果在各自子目录 |
| `planning_middle_demo/` | 任务规划中间层 v2 原型及本地演示结果；真实集成状态见 Obsidian 审查记录 |
| `planning/` | 早期规则规划原型、设计说明及测试，保留作对照 |
| `taskalloc/` | 任务分配环境、训练与评估脚本，保留历史实验入口 |
| `learning/` | Python 与强化学习基础小练习 |
| `资料/` | 需求与任务、平台调研、接口说明、汇报材料；Word、Markdown 与图片附件一起归档 |
| `outputs/` | 跨工程报告、审查证据、素材解析和展示图；各工程自己的运行结果仍放在各自 `outputs/` |
| `.work/`、`.workbuddy/` | 工具工作文件、历史备份与操作留痕；默认无需浏览 |

`simple_spread` 的脚本、模型和日志已在先前整理中移出本项目（见 `taskalloc/README.md`）；本次没有改动 WSL 中的 MARLlib 或训练结果。

## 文件维护

- 新的需求和参考文档放入 `资料/` 对应子目录，图片附件跟随同名 Markdown，避免重新散落在根目录。
- 正式报告与可独立打开的展示放入 `outputs/`；缓存、排版检查和一次性脚本放入 `.work/`。
- 不因版本较早就删除原型、报告或实验结果；仅删除可再生成缓存及确认相同的重复文件。
- 本次搬迁、删除明细及恢复备份见 [2026-10-28 整理记录](outputs/目录整理_20261028.md)。
