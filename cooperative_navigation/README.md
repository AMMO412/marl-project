双击 `启动演示.cmd`：重新运行当前配置并打开回放。无需服务或第三方依赖，使用 Windows Python 3。
已生成记录在 `outputs/verified_20261029/index.html`，可以直接双击打开。

## 已实现的流程

从源 SDF 的 robot_001/002/003 初始位置出发 → 分别到指定集合点 → 按实际位置核对全员到齐 → 依次经过两组预设检查点 → 返回完成反馈。每台有独立目标；未到齐不能进入下一阶段。轮流通行，一次仅一台移动，其余保持位置，规划时把其他两台作为障碍。使用已知静态几何上的膨胀栅格 A* 与折线路径运动，速度上限0.5米/秒。包络半径1.4米加0.35米余量。

这是二维运动学执行与反馈，未接入 Gazebo、ROS 或真实机器人，不包含作战规则、任务分配或策略训练。未参与的47台源模型不在本演示中实例化。记录中的位置是模拟实际执行位置，不是独立传感器测量。没有轮胎滑移、加减速和定位噪声模型。

## 修改与复现

编辑 `scenario.json` 的 `assembly` 与 `checkpoints`，每组按robots顺序给出各自的米制XY坐标。起点从SDF读取。建筑/围墙内、过近的目标会拒绝；不会自动挪动用户输入。

```powershell
py -3 cooperative_navigation/demo.py
py -3 cooperative_navigation/demo.py --config cooperative_navigation/scenario.json --out cooperative_navigation/outputs/my_run
py -3 -m unittest discover -s cooperative_navigation -p test_demo.py -v
```

每轮保存 scene.json、command.json、paths.json、trace.jsonl、events.json、feedback.json、source.sdf 和独立 index.html。输出目录必须不存在，避免覆盖。回放支持播放/暂停、重新开始、时间轴、阶段跳转、完整地图/任务区域和图层开关。

反馈区仅在播放到完成帧时显示成功；时间轴前段显示当时的位置和事件。点“看完成反馈”可检查本轮终态。
