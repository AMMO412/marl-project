# 原生兼容端功能范围

当前默认展示为浏览器工作台；本清单只描述 `desktop_app/src/` 的原生入口，不把浏览器新功能自动视为已用原生控件重做。启动与构建见 [桌面 README](README.md)。

| 能力 | 原生端 |
| --- | --- |
| 任务、编成与运行配置 | 表单、通用字段和 JSON 编辑，后端严格校验后冻结输入新建 |
| 五类任务专用表单、红方目标 | 使用共享后端目录和写回接口；保留扩展字段 |
| 地图与回放 | WebView2 画布；缩放/平移/图层、回放时间轴及平台定位 |
| 平台与高度 | 实际反馈、场景 z、历史曲线，缺失不补造、回退隐藏未来 |
| 运行与事件 | 记录筛选、载入回放、消息定位、输入复制为草稿 |
| 输出与报告 | 原始文件预览/另存、单平台明细、计划/执行指标及运行对比 |
| 全链路追溯 | 独立窗口加载本轮追溯页，查看实际任务→子任务→指令→反馈 |
| 删除与恢复 | 按轮移动至实际存储根目录 `.deleted/`，不删除运行中的轮次 |
| 动态编辑与续算 | 浏览器工作台提供完整入口；原生兼容端主要新建运行，不宣称完全同等操作 |

运行路径以实际后端 `outputs_root` 为准。产品场景以注册列表为准，不使用过去“六个/七个入口”的固定数量；旧输入仍可作为测试夹具或历史回放保留。

原生验证源码与历史证据分开：源码继续保留，已归档截图和旧轮次通过 [历史索引](../outputs/历史产物索引.md) 查询。历史检查仅适用于生成时版本，全部场景工况、目标机安装和外部平台联调仍待正式验证。
